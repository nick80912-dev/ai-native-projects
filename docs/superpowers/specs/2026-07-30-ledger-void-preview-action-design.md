# 整張收據作廢預覽按鈕設計

## 目標

更正收據畫面在完成「整張收據作廢」預覽後，只提供一個明確的最終送出動作「確認整張作廢」，避免同時顯示功能相同但名稱誤導的「重新預覽作廢」。

## 行為

- 尚未產生作廢預覽時，保留次要按鈕「整張收據作廢」。
- 產生作廢預覽後，主要按鈕顯示「確認整張作廢」並負責送出。
- 產生作廢預覽後，不再顯示次要的「重新預覽作廢」按鈕。
- 一般更正預覽流程維持原狀。

## 邊界

- 不修改 `saveLedgerCorrection`、preview signature、commit-last 或 canonical conflict 防護。
- 不修改 append-only 更正／作廢事件、資料格式、權限或歷史紀錄。
- 不新增新的送出路徑；只移除重複入口。
- App Shell cache 由 SW v70 升至 SW v71，供真機辨識本次介面修正。

## 驗收

- 測試鎖定作廢預覽後隱藏次要作廢按鈕。
- 測試確認「重新預覽作廢」不再存在。
- 測試確認「整張收據作廢」與「確認整張作廢」兩個正確階段文案仍保留。
- 完整 Node tests、文件標題、manifest JSON 與 diff 檢查通過。
