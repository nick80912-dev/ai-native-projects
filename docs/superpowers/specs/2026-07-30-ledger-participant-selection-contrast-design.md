# 分攤成員選取色差設計

## 目標

新增消費與更正收據共用的「分攤成員」按鈕，在選取後使用中度青綠底 `#d6e8e4` 與深色文字，讓選取狀態和區塊底色 `#f3f8f6` 明確區隔。

## 範圍

- 只修改 `.ledger-participant-choice.on`。
- 保留現有 `✓`、`aria-pressed`、邊框與文字色語意。
- 不定義或修補全域 `--mint`，避免連動其他頁面。
- 不修改分攤資料、點選 handler、權限或儲存流程。
- 「確認整張作廢」與「重新預覽作廢」同功能的問題本次只記錄討論結論，不納入實作。

## 交付

- 先新增會在現況失敗的 CSS 契約測試。
- 最小修改選取背景色。
- App Shell cache 由 SW v69 升至 SW v70，確保真機可辨識並取得本次驗收修正。
- 執行目標測試、完整 Node tests、文件標題檢查與 diff 檢查。
