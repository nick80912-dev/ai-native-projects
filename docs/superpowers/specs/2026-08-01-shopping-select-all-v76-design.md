# 採買多選全選與回歸強化設計

> 日期：2026-08-01
> 狀態：Bar 已核准，進入 v76 實作規劃
> 優先級：新 P1（採買流程完整化）
> 目標版本：SW／App v76

## 1. 目標與範圍

本批補齊採買清單的批次選取流程：進入多選模式後，在既有「取消多選」旁提供目前分頁的「全選／取消全選」，並完整回歸既有批次操作與 v75 照片附件流程。

本批不新增照片功能、不修改導航、不調整採買資料 schema、照片 IndexedDB、個人備份格式或全站設計 token。

## 2. 操作與畫面

### 2.1 清單頂部工具列

- 一般模式維持「`N 項　多選`」。
- 進入多選且尚未全選時顯示「`N 項　全選　取消多選`」。
- 目前分頁全部項目都被選取時顯示「`N 項　取消全選　取消多選`」。
- 「全選／取消全選」與「取消多選」組成同一個操作群組，位於項目數右側。
- 320px 寬度下三個資訊區仍保持單列，不產生水平 overflow；每顆按鈕的可點擊區至少 44×44px。

### 2.2 按鈕語意

- 「全選」只選取目前所在的「待買」或「已買」分頁，不跨分頁選取。
- 「取消全選」只清空目前選取，使用者仍停留在多選模式。
- 「取消多選」退出多選模式並清空選取。
- 全選後手動取消任一項，控制按鈕立即恢復為「全選」。
- 空清單不顯示多選、全選或取消全選入口。
- 全選或取消全選造成畫面重繪後，鍵盤焦點保留在切換後的對應按鈕。

### 2.3 既有介面保持不變

- 底部批次工具列繼續顯示實際選取數量與所在分頁可用動作。
- 多選模式仍隱藏單卡「部分購買」、「記帳」與操作選單。
- 卡片上的照片迴紋針、採買明細及照片操作不因多選模式改變。

## 3. 選取狀態

- 是否全選必須每次由目前分頁的實際項目 ID 與 `shoppingUiState.selected` 推導，不保存第二份 `allSelected` 狀態。
- 執行全選時，以目前分頁項目重建選取集合，不保留另一分頁、已刪除項目或其他 stale ID。
- 手動選取與取消選取後，頂部控制和底部計數必須由同一份 selection 狀態同步更新。
- 切換待買／已買、退出多選或批次操作成功後，清空 selection。
- 批次操作被既有 preflight 阻擋、執行失敗，或使用者取消刪除確認時，保留 selection 供使用者修正後重試。

## 4. 批次操作與錯誤邊界

全選只是產生既有批次操作所需的項目 ID 集合，不建立新的批次資料路徑：

- 待買：標記已買、建立消費、刪除。
- 已買：移回待買、建立消費、刪除。
- 建立消費繼續沿用 allocation 與 ledger link preflight，不得靜默略過被阻擋項目。
- 批次刪除繼續顯示實際選取數量及既有 ledger link 風險警告。
- 刪除含共同 `photoId` 的拆分項目時，繼續沿用 v75 最後引用消失才移除 Blob 的規則。

## 5. 照片附件回歸

本批不新增照片 UI，只完整重跑以下 v75 行為：

- 卡片只顯示無文字的迴紋針，不顯示縮圖。
- 詳情可查看照片；關閉按鈕避開 iPhone safe area，亦可向下滑關閉。
- 照片可替換、移除，重新載入後仍保存在本裝置。
- 個人備份不包含 `photoId`，還原不建立跨裝置懸空引用。
- 刪除最後引用時清除 Blob，共用引用尚存在時不得誤刪。

## 6. PWA 與版本

- `app-version.js` 由 v75 升至 v76。
- `sw.js` 只將快取版本字串由 `okayama-trip-v75` 改為 `okayama-trip-v76`；不修改 install、activate、fetch、SHELL 或其他 Service Worker 行為。
- `netlify.toml` 必須保持 diff 0。
- 不變更 `PERSONAL_STATE_VERSION` 或任何採買資料 schema。

## 7. 驗收

### 7.1 選取與批次操作

- Node 測試涵蓋空清單、部分選取、全選、取消其中一項、取消全選、stale ID 與待買／已買分頁隔離。
- Playwright 驗證待買與已買各自全選；切換分頁與退出多選會清空 selection。
- 批次操作成功後清空 selection；preflight 失敗、執行錯誤或取消確認時保留 selection。
- 全選後回歸待買的標記已買／建立消費／刪除，以及已買的移回待買／建立消費／刪除。

### 7.2 行動版與可存取性

- 320×700、375×812、390×844 的 `scrollWidth - clientWidth = 0`。
- 項目數、全選控制與取消多選保持同列；按鈕點擊區至少 44×44px。
- 身分列、採買卡與底部批次工具列不換行、不溢位且不遮住最後一張卡。
- 控制文字正確切換，鍵盤焦點在重繪後仍可預期。

- 完整重跑 v75 照片附件 Playwright 情境。
