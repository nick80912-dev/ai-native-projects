# Ledger 新增消費快速版面設計

## 目標

讓單品新增消費聚焦在「金額 → 明細 → 代購／分攤 → 儲存」，縮短預設表單高度；不改帳務、分攤、代購、同步或資料格式。

## 核准方案 A

- 金額、明細、帳本與幣別維持既有順序及控制方式。
- 個人帳維持「這筆是代購」開關，只有開啟後才顯示代購對象。
- 團體帳將成員 chips 預設收成一列「分攤成員／全員 N 人」或「已選 N 人」，點擊後才展開既有成員選擇器。
- 原本「其他資訊」「稅與優惠券」「更多細節」三個入口合併為單一「其他資訊（選填）」；摘要依序顯示日期、類別、支付方式與有無備註。
- 展開「其他資訊」後仍可編輯店家、日期、時間、類別、支付方式、價格方式、稅率、優惠券與備註，原驗證及金額計算語意不變。
- 「儲存」維持主要按鈕；「儲存並再記一筆」以目前主題 action／card token 產生低彩度次要底色，但保留既有 44px 以上觸控區與 save workflow。
- 多品項表單、編輯／更正資料語意、calculator、schema、repository、同步與 Service Worker 不在本批擴張。

## 無障礙與窄螢幕

- 分攤摘要使用正式 button、`aria-expanded` 與 `aria-controls`。
- 鍵盤從明細前進時，團體帳聚焦可見的分攤摘要，不聚焦收合區內的 hidden chip。
- 320／375／390px 不得產生水平 overflow；個人／團體切換、分攤展開、代購展開與其他資訊展開均需以真實 renderer 驗證。
